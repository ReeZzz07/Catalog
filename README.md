# EGE Solver - Решение заданий ЕГЭ с помощью ИИ Qwen

## Описание

Приложение для автоматического решения заданий ЕГЭ по различным предметам с использованием мультимодальной ИИ-модели Qwen.

## Возможности

- **Поддержка 11 предметов**: Биология, Физика, Химия, Математика (база/профиль), Русский язык, История, Обществознание, География, Информатика, Литература
- **Мультимодальность**: Обработка текста и изображений (графики, схемы, чертежи)
- **Разные типы ответов**: Краткий ответ, выбор варианта, последовательность цифр, соответствие
- **Графический интерфейс**: Удобное управление настройками и запуском
- **Нативная установка**: Установка как обычное приложение с ярлыками

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements_ui.txt
```

### 2. Запуск графического интерфейса

```bash
python run_ui.py
```

### 3. Установка как нативного приложения (опционально)

```bash
python install.py
```

После установки:
- На рабочем столе появится ярлык приложения
- Приложение можно добавить в автозагрузку
- На macOS создаётся .app bundle
- На Linux создаётся .desktop файл

## Использование через UI

1. **Вкладка "Настройки"**:
   - Введите API ключ Qwen (получить на https://dashscope.aliyun.com/)
   - Выберите модель (рекомендуется `qwen-vl-max` для задач с изображениями)
   - Выберите предмет
   - Настройте лимиты (макс. задач, размер пакета, таймаут)
   - Нажмите "Сохранить настройки"

2. **Вкладка "Решение"**:
   - Нажмите "Запустить решение"
   - Следите за прогрессом в логе
   - Дождитесь завершения

3. **Вкладка "Результаты"**:
   - Просмотрите список файлов с результатами
   - Откройте папку с результатами

## Использование через командную строку

```bash
# Запуск прототипа (биология, mock режим)
python -m ege_solver.solver

# С реальным API
export QWEN_API_KEY="your-key"
export QWEN_MODEL="qwen-vl-max"
python -m ege_solver.solver
```

## Конфигурация

Настройки хранятся в файле `ege_solver_config.json`:

```json
{
  "api_key": "your-api-key",
  "api_base": "https://dashscope.aliyuncs.com/compatible-mode/v1",
  "model": "qwen-vl-max",
  "subject": "biologiya",
  "max_tasks": 10,
  "batch_size": 5,
  "timeout": 60
}
```

## Доступные модели Qwen

| Модель | Описание | Рекомендация |
|--------|----------|--------------|
| `qwen-vl-max` | Лучшая мультимодальная | ✅ Для задач с изображениями |
| `qwen-vl-plus` | Быстрая мультимодальная | Для простых задач с графикой |
| `qwen-max` | Максимальная текстовая | Для сложных текстовых задач |
| `qwen-plus` | Баланс скорости и качества | Универсальный выбор |
| `qwen-turbo` | Самая быстрая | Для тестирования |

```json

  "answer_type": "short",
  "topics": ["Биология клетки"],
  "raw_answer": "Ответ: митохондрия",
  "extracted_answer": "митохондрия",
  "normalized_answer": "митохондрия",
  "is_valid_format": true,
  "status": "success"
}
```

## Получение API ключа

1. Зарегистрируйтесь на https://dashscope.aliyun.com/
2. Создайте API ключ в личном кабинете
3. Вставьте ключ в настройках приложения

## Архитектура системы

1. **TaskLoader** - загрузка задач из JSONL, парсинг HTML, обработка изображений
2. **PromptBuilder** - создание специализированных промптов для каждого типа задач
3. **QwenClient** - отправка запросов к модели (или mock-режим)
4. **AnswerValidator** - проверка и нормализация ответов
5. **EGESolver** - координация всего процесса
6. **UI (CustomTkinter)** - графический интерфейс пользователя
